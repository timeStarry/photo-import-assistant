# Photo Import Assistant · 相机导入助手

Windows 存储卡照片与视频导入工具，使用原生 WPF 界面和托盘运行方式。

- 按卡内 UUID 登记存储卡，支持改名、离线管理和独立导入偏好。
- 导入到 Windows 文件夹、SMB 网络共享、直接 WebDAV 或 S3 兼容存储，支持位置优先级和批准的失败切换。
- 原生位置类型表单、Windows 凭据管理器、连接测试与导入前只读预检。
- 小文件与大文件公平排队、最多 4 个文件并发、阶段及字节进度、无进展超时。
- 完整 SHA-256 校验、同名冲突保护和取消操作。
- 导入前对比已启用位置的媒体内容，相同副本不再计入待导入；支持排除文件后缀。
- SMB 副本完成校验后可询问清理原件；本地、映射盘、直接 WebDAV 和 S3 副本保留原件。
- 浅色、深色、跟随系统主题，以及可配置的登录自启。

## 构建与测试

要求 Windows 10/11、.NET Framework 4.8。推荐使用 PowerShell 7；构建使用 Windows 自带的 .NET Framework C# 编译器，无需下载依赖。

```powershell
pwsh -File .\scripts\build.ps1
pwsh -File .\scripts\test.ps1
```

程序位于 `bin\PhotoImport.exe`。测试报告与合成界面渲染位于 `artifacts\`；协议测试使用回环模拟服务器，不访问实际 SD 卡、NAS、云账户或登录任务，也不写入 Windows 凭据。

也可使用 Visual Studio / MSBuild 打开 `PhotoImport.sln`，安装 .NET Framework 4.8 开发工具后构建。

## 安装与使用

```powershell
pwsh -File .\scripts\install.ps1
```

安装脚本创建当前用户的 `PhotoImport-Agent` 登录任务，以及桌面和开始菜单快捷方式。已有助手正在运行时，请先从托盘菜单退出再安装。SMB 使用当前用户网络凭据；WebDAV 尝试复用匹配位置的 Windows 通用凭据，必要时在位置编辑器保存账号。S3 的 Access Key / Secret Key 同样保存到 Windows 凭据管理器，配置只保存引用。

1. 在“导入位置”添加照片保存位置。全新配置没有预设服务器或文件夹。
2. 插入 SD 卡，确认登记，或将格式化后的卡关联到已有记录。
3. 等待目标内容对比；确认框展示新增数量、本次预检状态、首选和批准的备用位置，可仅更改本次位置或设为默认。
4. 查看读取／上传／校验字节进度，完成后按副本的清理安全条件决定是否提供清理确认。

新增位置默认选择 Windows 文件夹，已有位置顺序不自动改变。“测试连接”会写入并读回本次随机小文件，验证协议安全发布能力；插卡和确认前预检只读，不把可访问误报为写入已验证。测试临时对象仅在所有权可确认时清理；网络响应丢失或缺少校验条件时可能保留，界面会提示。

“设置 → 传输”可配置最大并发（默认 2，上限 4）、自动调整、无进展超时（默认 180 秒）和大文件阈值（默认 256 MiB）。最多一个大文件同时运行，混合队列保留小文件通道。超时按字节／阶段进展重置，不限制整个视频的总时长。当前不提供 SSD 缓冲、跨程序重启断点续传或分片并行；S3 大文件使用有界内存分片，WebDAV 以单文件流传输。

WebDAV 不经过 Windows WebClient，使用临时对象及 `MOVE` / `Overwrite:F` 无覆盖发布；服务器不支持时失败回退，不采用危险覆盖。S3 需要支持条件 PUT、条件分片完成及测试对象的条件清理，不把 ETag 当作完整 SHA-256。两种直接后端完成上传后均完整读回校验；未具备远端锁定／不可变版本清理保护，当前保留卡内原件。

在“设置 → 文件范围 → 排除后缀”配置不导入的媒体后缀，逗号或空格分隔，例如 `.jpg, .mov`。只扫描 DCIM 下支持的照片和视频，Nikon `.DAT` 等辅助文件始终忽略。

目标对比递归检查已启用位置内的支持媒体，按文件大小筛选后做 SHA-256 校验，支持目标文件改名。同名同大小但不同内容仍可导入。目标不可达、文件不可读或对比无法确认时，不把它当作重复文件。首次对比大量照片或视频可能需要较长时间，可取消。

对比结果在本次插卡会话中用于展示，不会每四秒重复读回全部媒体。拔插卡、手动“刷新”或点击“导入”、修改位置或排除规则、媒体变化及完成导入后重新对比；目标文件被外部删除或修改后，可点击“刷新”更新待导入数量。确认期间候选快照发生变化，本次确认作废。已有副本只影响候选列表，不授权清理原件。

关闭窗口会收起至托盘；退出应用使用托盘菜单。关闭登录自启后，仍可通过快捷方式手动启动。位置修改在下一批导入生效。

设置、登记、日志和导入凭据保存在 `%LOCALAPPDATA%\PhotoImport`，不属于项目源码。支持 DCIM 下的 JPG/JPEG、NEF/NRW、MOV/MP4/AVI 和 TIF/TIFF。

```powershell
.\bin\PhotoImport.exe --preview

.\bin\PhotoImport.exe --render-previews .\artifacts\ui-previews
```
