# 架构与数据安全

## 用户会话

`MainWindow` 的 WinForms 宿主处理托盘与设备通知，`FluentView` 和对话框使用 WPF/XAML。程序在登录用户的交互会话中运行；注销后不运行。登录自启开关只调整任务的登录触发器，保留手动启动能力。

状态保存在 `%LOCALAPPDATA%\PhotoImport\state.json`。文件通过临时写入与替换保存，并保留上一份 `.bak`。日志为 `agent.log`；`jobs` 和 `imports` 保存每文件操作与校验凭据。这些运行数据不提交到 Git。

## 卡片识别

Windows 设备事件触发扫描，并每四秒核对可移动磁盘。扫描在独立进程中执行，超时后重试。

登记令牌写入卡根目录 `.photoimport-id.json`。这是应用生成的 UUID，不是硬件序列号。传输前同时检查卡内 UUID、文件系统序列号、容量与源文件快照；盘符或 Windows Volume GUID 不作为独立身份凭据。

格式化会移除令牌，需要重新关联。完整克隆卡也会复制令牌；同时发现相同 UUID 时阻止导入。当前仅扫描 Windows 上报为可移动磁盘的设备。

## 位置与传输

位置显式区分 Windows 文件夹、SMB、WebDAV 和 S3。旧 WebClient UNC 配置在运行快照中识别为直接 WebDAV URL，不改变已保存优先级。`DestinationRecord` 保存类型、地址、Bucket/Region/Prefix 和凭据引用；密码、Secret Key 不进入 JSON。`CredentialStore` 只读取明确引用或与 WebDAV 来源匹配的通用凭据，编辑系统凭据会创建应用独立引用，不覆盖系统账户。

每批开始时只读预检，确认窗显示本次状态、首选和批准的备用位置。确认后冻结位置、失败策略、并发与超时。只读可达不证明可写；显式连接测试才写入随机小对象。每文件由可终止子进程执行，上传和校验持续输出阶段及字节进度；父进程只在持续无进展时中止，不使用固定大文件总时长。取消或拔卡会中止当前操作；无法确认子进程退出时禁止新操作。并行批次在清除 busy 前观察全部已启动子任务。

`ImportScheduler` 维持小文件与大文件队列，三个小文件轮次后安排一个大文件，最多一个大文件同时运行。用户上限 1–4，自动模式从单流测量已完成字节吞吐并探测上限，吞吐下降／失败时降低压力；混合队列在上限允许时保留小文件通道。不是无限线程或按标称网卡带宽猜测卡速。当前无 SSD 缓冲或跨重启续传。

本地文件先写临时文件、刷新并读回校验，再无覆盖地改名。同名文件即使大小相同也核对完整 SHA-256，不同内容使用带哈希的文件名。不导入文件系统链接或重解析点。

WebDAV 使用直接 PROPFIND/HEAD/GET/PUT/MKCOL/MOVE，上传到随机 partial，`Overwrite:F` 发布，禁止跨来源重定向。上传时同时计算源 SHA-256，避免新文件预先完整读卡；发布后重新 GET 完整校验。只有来源校验明确的 partial 才能条件清理；响应丢失时保留不确定对象。旧 Win32 WebClient 传输代码仅保留为历史夹具路径，不用于正常 WebDAV 导入。

S3 使用 SigV4、ListObjectsV2、条件 PUT 或条件分片完成；分片内存有界，未完成上传仅按本次 uploadId 中止。兼容端点先在独立测试对象上核验条件写入，不测试覆盖用户对象；失败时拒绝上传。ETag 是协议版本标识，不等于文件内容哈希，副本必须完整读回 SHA-256。没有固定对象版本／远端锁定的清理条件时不授权源删除。

## 候选导入与排除

扫描仍以照片/视频白名单为边界，DAT 等辅助文件不在媒体范围内；用户可在设置中进一步排除后缀。缺失配置迁移为 `.dat`，主动清空排除列表会保留。规则在每次候选规划时冻结，导入使用确认过的候选快照。

`CandidatePlanner` 在隔离子进程中只读列举所有已启用位置（含备用），不依赖旧导入日志。仅枚举支持的媒体和与源文件相同的长度；目录层级限制 16，匹配长度的目标文件限制 100,000，跳过重解析点和 partial。目标无法列举时保留未确认的候选并提示对比不完整。

内容匹配使用完整 SHA-256，源快照与卡片身份核验沿用传输引擎，匹配时重新打开并锁定目标及祖先。改名的相同内容也能识别。单次规划仅缓存目标的非匹配哈希；正匹配始终重新读回。候选对比不写目标、不复制文件、不返回校验凭据或删除授权。

界面在规划完成前隐藏候选数量并禁止导入。源身份、源文件元数据、已启用目标与排除规则组成会话展示缓存键；拔卡、刷新、设置变化和导入完成使缓存失效。每四秒磁盘扫描不重复哈希；目标外部变化需刷新。手动导入前重新对比；自动插卡提示使用刚完成的规划。确认后再次验证最新磁盘快照、目标设置和设备事件代次，不一致则作废确认并提示重试。取消、超时或源验证失败不猜测候选，显示重试入口。

## 原件清理

只有 SMB（显式普通 UNC）的成功校验凭据能进入原有锁定清理流程。本地文件夹、映射盘、直接 WebDAV 和 S3 副本始终保留原件，与位置优先级无关。直接后端使用独立凭据类型，不能伪装成旧 remote 句柄凭据绕过安全检查。

清理前重新锁定并验证源文件、目标文件及 SHA-256；不匹配则保留原件。删除按已验证文件句柄执行。对话框默认保留，X/Esc 取消且不保存“记住选择”。

保存到备用位置后不会自动补传到原首选位置。再次插卡或手动导入可以重新尝试。
