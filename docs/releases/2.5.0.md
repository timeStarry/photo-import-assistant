# 相机导入助手 2.5.0

## 新增

- 文件整理：按拍摄日期（默认）、按导入日期、保留卡内目录或直接保存。
- 日期目录支持按天、按年和年／月；不存在的目录在开始写入时自动创建。
- 可选 RAW／JPG 分目录，视频和 TIFF 分别保存，原文件名不变。
- 拍摄时间缺失默认进入“未知日期”，也可明确使用文件修改日期。
- 导入确认显示日期分组、实际路径及未知／回退日期数量，规则修改后重新规划和确认。
- 同一批次的整理结果在本地、SMB、WebDAV、S3 和失败回退之间保持一致。

## 保持与边界

- 不搬动历史文件；旧 DCIM 和新日期目录都继续参与完整内容去重。
- RAW／JPG 分目录为可选项，默认关闭，在“设置 → 文件整理”开启。
- 照片读取经典 TIFF／EXIF 原始拍摄时间；MOV／MP4 读取受支持的 QuickTime 时间字段。不支持的元数据（包括 AVI 时间）不会猜测日期。
- 视频整数时间默认按相机时间解读；确定设备写入 UTC 时可在高级设置启用转换并选择时区。
- 不改变原件清理保障：本地、映射盘、直接 WebDAV 和 S3 副本保留 SD 原件。

## 下载与使用

下载 `PhotoImport.exe`。需要 Windows 10/11 和 .NET Framework 4.8，无额外元数据工具或解码器依赖。

已有安装请先从托盘退出助手，再更新启动入口；不要在传输或清理期间替换。源码构建与登录自启安装方法见仓库 README。`SHA256SUMS.txt` 可用于核对下载文件。
